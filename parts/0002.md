# The Square Struct
The Square struct identifies a single square on the board. Internally it is stored as a single index from 0 to 63, with a0 = 0 and h8 = 63, rather than as separate file and rank values.

---

## Construction
Squares can be built from a file and rank pair, from a raw index, or parsed from algebraic notation (e.g. `"e4"`). Named constants are also provided for every square, such as `Square::E4`.

---

## Display
Converting a square back to algebraic notation is done via the standard `Display` trait, so a square can be printed or turned into a string directly.
